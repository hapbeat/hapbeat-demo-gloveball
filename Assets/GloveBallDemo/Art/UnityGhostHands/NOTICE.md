# Unity ghost hand assets

These are Unity sample assets, not Hapbeat-authored or CC0 assets.

- `Materials`, `Shaders`, `Textures`: Hands Interaction Demo from XR Interaction Toolkit 3.3.1. XR Interaction Toolkit copyright © 2025 Unity Technologies; Unity Companion License: https://unity.com/legal/licenses/unity-companion-license . Retain this notice and the associated license information. The current package copy of the combined finger texture is included alongside the older texture because the material contains references to both GUIDs.
- `VolleySkinHand.mat` is derived from `Materials/Unity_Hand_Medium.mat` (skin tint and fade values only) and remains subject to the same notice.
- Runtime joint motion uses the project's `com.unity.xr.hands` package, not copied interaction scripts. The ghost visual intentionally excludes the sample's poking, grabbing, menus and locomotion components.

## Hand meshes (not included)

The Unity XR Hands HandVisualizer sample meshes (`LeftHand.fbx`, `RightHand.fbx`; XR Hands copyright © 2024 Unity Technologies) are licensed under the Unity Package Distribution License (https://unity.com/legal/licenses/unity-package-distribution-license), which permits distributing them only as part of built application binaries. They are therefore **not** part of this repository.

At runtime `VolleyHandModelResolver` loads them from `Resources/HapbeatPrivate/UnityHands/` when a private copy is present in the project (`Assets/HapbeatPrivate/`, git-ignored). Otherwise it uses the Hapbeat-authored placeholder hands in `Assets/GloveBallDemo/Art/FallbackHands/`, generated by `Assets/Editor/VolleyPlaceholderHandBuilder.cs` from simple capsules with XR Hands joint names.

Use requires a valid Unity engine license and compliance with the applicable third-party notices.
